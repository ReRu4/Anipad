# 🌸 Anipad — Органайзер Аниме-Коллекции и Торрентов

Интерактивный веб-каталог и автоматизированный органайзер для аниме-торрентов, закладок (Anixart / Shikimori) и постеров высокого разрешения с поддержкой множества студий озвучки.

---

## ✨ Основные возможности

1. **Единый веб-каталог без дубликатов (`Каталог_Аниме.html`)**:
   - Связка всех сезонов, фильмов, OVA и спешлов в **единую франшизу** (1 карточка = 1 тайтл).
   - Индивидуальные постеры под каждый сезон с плавной анимацией смены обложки при переключении.
   - Модальное окно по клику на постер: список жанров, подробное описание сюжета на русском языке, статус и рейтинг.

2. **Выбор качества с точным весом в ГБ/МБ**:
   - Точный расчет размера раздач в ГБ/МБ через встроенный Bencode-парсер `.torrent` файлов.
   - Выпадающий список качества с явным указанием диапазона серий (например: `1080p HEVC (2.8 ГБ) • [1-12 серий]`).
   - Умное скрытие неполных/старых онгоинг-пакетов под кнопку **«👁️ Показать остальные»**.

3. **Мульти-студийная поддержка озвучек без перемешивания**:
   - Четкое разделение торрентов по отдельным папкам студий:
     - `торренты/AniLibria/`
     - `торренты/DreamCast/`
     - `торренты/SHIZA_Project/`
     - `торренты/AnimeVost/`
     - `торренты/StudioBand/`
     - `торренты/AniDUB/`
     - `торренты/MultiDub_Sub/`
   - Прямые ссылки на онлайн-релизы **AniLiberty**, **AnimeGO** (все озвучки) и **Nyaa.si** (Multi-Subs/RAW).

4. **Автоматический парсинг и автообновление торрентов**:
   - Скрипт `scripts/anilibria_updater.py` скачивает новые торренты и серии с AniLibria/AniLiberty напрямую через API.
   - Скрипт `scripts/studio_crawler.py` индексирует раздачи других студий.

5. **Автономность и динамическая загрузка CSV**:
   - В шапке каталога есть кнопка **«📂 Загрузить CSV»** (Drag-and-Drop) — можно загрузить любой экспорт закладок Anixart/Shikimori, и все статусы/оценки обновятся на лету.

## 🚀 Запуск и использование

### 1. Открыть каталог
Просто откройте файл **`Каталог_Аниме.html`** в любом браузере (Chrome, Edge, Firefox, Safari). Работает полностью автономно оффлайн.

### 2. Запуск организации торрентов
```bash
python anime_organizer.py
```
или с указанием своего CSV файла закладок:
```bash
python anime_organizer.py --csv "путь_к_файлу.csv"
```

### 3. Автообновление новых серий с AniLibria/AniLiberty
```bash
python scripts/anilibria_updater.py
```

### 4. Индексация сторонних озвучек
```bash
python scripts/studio_crawler.py
```
